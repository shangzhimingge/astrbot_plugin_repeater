# astrbot_plugin_repeater — 群复读机

AstrBot 群复读机插件：当群里连续 **N 个不同的人** 发送了相同消息时，机器人自动跟一条一模一样的消息。

适用于 **NapCatQQ（OneBot v11）**，通过 AstrBot 的 `aiocqhttp` 适配器工作。

例如：群里刷屏「疯狂星期四V50」，当检测到 **3 个不同的人** 都发了这条消息（阈值可自定义），机器人就会自动跟一条「疯狂星期四V50」。

## 功能特性

- ✅ 按群独立开关复读机模式
- ✅ 自定义触发人数（默认 3，范围 2~50）
- ✅ 按「不同的人」计数：同一个人刷 10 条也只算 1 人
- ✅ 只统计**连续**发送的相同消息，内容一变自动重新计数
- ✅ 同一连续有效文本段只成功复读一次，内容变化后可再次触发
- ✅ 可选触发冷却时间，防止机器人刷屏
- ✅ 群设置持久化保存，重启不丢失

## 安装

### 方式一：WebUI 上传安装（推荐）

1. 将 `astrbot_plugin_repeater.zip` 上传到 AstrBot WebUI → 「插件管理」→ 上传安装；
2. 安装后重启插件或在插件管理处点击「重载」。

### 方式二：目录放置

将 `astrbot_plugin_repeater` 文件夹放入 AstrBot 的 `data/plugins/` 目录下，然后在 WebUI 中启用。

## 配置（WebUI）

在 AstrBot WebUI → 插件配置 中可修改全局默认值：

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enable` | bool | `true` | 插件默认是否启用复读机模式 |
| `command_permission` | string | `bot_owner` | 子指令最低权限：`member` / `admin` / `owner` / `bot_owner` |
| `threshold` | int | `3` | 触发复读所需的不同人数（2~50） |
| `cooldown` | int | `0` | 触发后冷却秒数，`0` 表示无冷却 |

## 群内指令

指令前缀以 AstrBot 设置为准（默认 `/`）。
以下五个子指令统一受 `command_permission` 控制，权限从低到高为群成员、
群管理员、群主、BOT 主人；默认仅 BOT 主人可用。群管理员和群主身份读取
OneBot 群成员角色，BOT 主人身份使用 AstrBot 管理员配置判定。角色缺失或
未知时按群成员处理；配置值异常时记录警告并按 `bot_owner` 处理。

| 指令 | 说明 |
|---|---|
| `/复读机 开` | 开启本群复读机模式 |
| `/复读机 关` | 关闭本群复读机模式 |
| `/复读机 阈值 5` | 设置触发人数为 5 人 |
| `/复读机 冷却 30` | 设置触发冷却为 30 秒（0 表示无冷却） |
| `/复读机 状态` | 查看本群复读机当前状态 |

## 行为说明

- 机器人**不会**复读自己的消息，也不会把 `/复读机 ...` 指令当成复读内容；
- 只复读**纯文本**消息（图片/表情等非文本消息不参与计数）；
- 「连续」指消息内容必须相同且中间没有其它内容插入；内容一变，计数清零重新开始；
- 同一连续有效文本段成功复读后不再累计；插入不同有效文本会开始新段，因此之后相同文本可重新达到阈值并触发；
- 冷却期内发送者不计数，但不同有效文本仍会切换文本段；冷却结束后的第一条消息只计 1 人；
- 发送成功后才提交「本段已复读」和冷却时间；发送异常会记录日志，下一条相同文本可重试；
- **复读消息是直接发送的**：即使 AstrBot 开启了「回复时引用发送人消息 / 回复时 @ 用户」，复读时也**不会**引用或 @ 最后一位发送者，保证纯复读效果（普通 LLM 回复的引用/@ 不受影响）。

## 常见问题

**Q：机器人完全不复读？**
A：① 检查是否已执行 `/复读机 开`；② 检查 WebUI 中插件 `enable` 配置；③ 确认 AstrBot 的适配器是 `aiocqhttp`（OneBot v11），其他适配器需自行去掉 `main.py` 中的平台过滤装饰器。

**Q：为什么复读时不引用/不 @ 最后一位发送者？**
A：AstrBot 的「回复时引用发送人消息 / 回复时 @ 用户」是在结果装饰阶段统一加上的，插件用 `event.send()` 直接发送复读消息绕过了该阶段，因此复读保持纯文本跟一条。这是有意设计，普通 AI 回复仍会正常引用/@。

**Q：一个人刷屏会不会触发？**
A：不会。按「不同的人」计数，同一个人重复发只算 1 人。

**Q：想支持其他平台（如 QQ 官方、Telegram）？**
A：删除 `main.py` 中 `on_group_message` 上方的 `@filter.platform_adapter_type(...)` 一行即可（保留群聊过滤即可）。

**Q：数据存在哪里？**
A：群设置保存在 AstrBot 的 `data/astrbot_plugin_repeater/state.json`，不在插件目录内，更新/重装插件不会丢失。
